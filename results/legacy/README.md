# Pre-guide benchmark archive

These files were collected before the guide-compliant `profiling/benchmark.py` entry point existed. They are preserved for local reference only and must not be cited as final Task 1 evidence: the previous forward mode did not use `no_grad`, the mode and output schemas differ from the guide, and CV/required metadata were absent.

Use `profiling/collect_benchmark.py` to regenerate the compliant Task 1 result set.
